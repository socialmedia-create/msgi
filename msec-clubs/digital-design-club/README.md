# Digital Design Club Website

A responsive, playful pastel website for the Digital Design Club, Department of Information Technology, Meenakshi Sundararajan Engineering College.

## Run it

1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For the best local development experience, use VS Code with the Live Server extension and choose **Open with Live Server**.

No package installation or build step is required. This project uses plain HTML, CSS and JavaScript.

## What's included

- Vision and mission, club tagline (Create. Ideate. Elevate.)
- Home, About, Events, Gallery, Team and Contact sections
- Responsive desktop and mobile layouts
- Mobile navigation menu
- Light/dark theme toggle (preference saved in local storage)
- Event category filters
- Scroll reveal animations and decorative motion
- Interactive gallery lightbox
- Contact form validation with an explicit frontend-demo notice
- Keyboard Escape support and reduced-motion preference support

## Important before submitting / publishing

- Event photos in `assets/photos/` are real; confirm everyone pictured is happy for them to be published, and check captions/categories.
- Confirm event dates, event descriptions and the current committee details with the club.
- Club email and LinkedIn are added (no Instagram yet — add a link in the Contact section and footer when it exists). Add the official logo if available (address in the Contact section comes from the campus location stamp on a photo).
- The contact form is frontend-only and does **not** send or store messages. Connect a backend or form service if real submissions are required.
- Google Fonts load over the internet; system fallbacks are included.

## Files

- `index.html` — page structure and content
- `styles.css` — styling, responsive layouts, animations and dark mode
- `script.js` — menu, theme, event filters, gallery interaction and form demo
- `assets/photos/` — optimized event photos used by the gallery and team section
- `assets/favicon.svg` — simple club-inspired favicon

- `assets/logo-full.png`, `assets/logo-emblem.png`, `assets/favicon.png` — club logo variants (emblem used in header/footer, full logo in Contact)
